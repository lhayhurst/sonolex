# Welcome

Bring some heat to your music creation workflow with nanobox | fireball, a polyphonic wavetable mini synthesizer with intuitive touchscreen control. Featuring eight voice polyphony, two wavetables and an oscillator, Fireball unlocks a huge array of sounds—from punchy and aggressive leads to atmospheric pads. Touchscreen X/Y control allows you to instantly morph and shape sounds with the swipe of a finger. Choose from hundreds of professionally designed presets and wav files, or quickly create your own patches with deep parameter control via the 2" touchscreen. Integrate fireball seamlessly with your existing tabletop gear—or create on-the-go thanks to a compact design that fits in the palm of your hand.

## Firmware Version

This User Guide is based on Version 1.0.10 of the nanobox | fireball firmware. To see which version is on your product, push the Home button to go to the main dashboard, then push the Left Arrow button to go to the nanobox Config screen. The loaded firmware version is displayed at the top of the screen, just to the left of the rotating tempo icon. Version 1.0.10 is available for download for free at the 1010music forum after you register.

# Quick Start Guide

Quick setup and orientation for the nanobox fireball.

## Get Set Up

1. Insert the microSD card if it's not already inserted. The card must be in the slot for fireball to load. The card is spring-loaded—push to eject when needed.
2. Connect the stereo Line Out to your mixer, speakers or headphones. Be sure to use a TRS cable to hear both channels.
3. Connect an optional MIDI controller to the MIDI IN jack. TRS Type A and B are supported. Use the included adapter to connect to controllers that use MIDI 5 Pin DIN.
4. Connect the USB power cable. Fireball can be powered by a standard 5V, 500 mA USB power adapter or USB battery. Fireball will start up as soon as it receives power.
5. Play notes on the MIDI controller or the Grid Keyboard screen and you are making music!

## Find Your Way Around

HOME BUTTON: Access the Dashboard and the Performance Stack.
LAYER BUTTON: Cycle between the layers in the current feature stack.
CONTROL PANEL: Gauges show the real time state of each control. Touch to access the related settings.
LEFT ARROW BUTTON: Go back to the previous screen.
RIGHT ARROW BUTTON: Access more detail about the current selection.
KNOBS: Control X and Y modulators, scroll through a list and choose settings.
X/Y GAUGES: Values of the X and Y modulators.
CLOCK: Shows the tempo.
PRESET NAME: Touch to load and save presets.
WAVETABLE GRAPHS: Touch to configure the Main Oscillators.

## Navigate the Stacks

Performance Stack: X/Y Modulator, Grid Keyboard
Main Oscillator Stack: Wavetable 1, Wavetable 2, Oscillator
Filter Stack: Filter 1, Filter 2
Envelope Stack: Envelope 1, Envelope 2
Modulation Stack: LFO 1, LFO 2, Sequencer
FX Stack: FX 1, FX 2

Push the Layer Button to cycle through a feature stack. Touch the graphs or buttons on the Dashboard to access feature stacks.

## Set the Controls

Graph: Drag the handle to adjust the settings.
Parameter List: Use the top knob to scroll through the list. Use the bottom knob to select a value.
Stack Position: See where you are in a stack.
Modulation Slots: Push the Right Arrow while row is selected to apply MIDI and Internal modulation.

## Access High Level Configuration Options

nanobox Configuration: Push the Left Arrow from the Dashboard to configure settings at the nanobox level.
Preset Configuration: Push the Right Arrow from the Dashboard to configure settings at the preset level.
Preset Name: Touch to load and save presets.

## Explore the Sounds

Touch the Preset Name at the top of the Dashboard to select a different preset.
Try the Modulation Wheel on your MIDI Controller with different presets to add sometimes subtle, sometimes surprising effects.
Turn the knobs on the dashboard and drag your finger on the X/Y Modulation Grid to explore how each preset uses the X and Y modulators.
Set the Line Thru amount on the nanobox Configuration screen to control how much of the Line Input signal is sent to the FX engine.

## Adjust the Volume and Brightness

1. Push Home to go to the Dashboard if not already there.
2. Push the Left Arrow button to go to the nanobox Config screen.
3. Use the knobs to adjust the values of the Brightness and Volume parameters.

# The Dashboard

The dashboard is your window into what nanobox | fireball is doing. Here you can see the waveform configured for each of the two granulators, monitor the state of each of the audio control features, and access all of the features available. You can get to the dashboard by pushing the Home button from any other screen.

## Dashboard - See and Touch

Wavetable One and Two: The graph represents a single cycle of the wavetable for the oscillator. The graph is animated to show the behavior of the earliest triggered note that is still playing. Touch a graph to open the Wavetable Settings for that oscillator.

X and Y Gauges: X and Y are two manually controlled modulation sources. These gauges show their current values, with zero in the middle. From the dashboard, turn the top knob to control X and the bottom knob to control Y.

Preset Name: Displays the currently selected preset. Touch to choose a different preset or save your settings.

Clock Icon: Rotates one quarter turn for each beat in a 4/4 measure. Push the Right Arrow while on the Dashboard to see the Preset Config Screen where you can change the tempo.

## Dashboard - Control Panels

FILT: Top and bottom gauges display the Cutoff (for Low Pass and High Pass filters) or Center Frequency (for Notch and Band Pass filters) for FILT1 and FILT2. Touch the panel to access the Filter Settings stack.

ENV: Top and bottom gauges display the level of the signal as controlled by the envelope for ENV1 and ENV2. Touch the panel to access the Envelope Settings stack.

LFO/SEQ: Top two gauges display the current value being output by LFO1 and LFO2. Bottom gauge displays the current value being output by the SEQ. Touch the panel to access the LFO + SEQ Modulation stack.

FX: Top and bottom gauges display the value of the primary parameter for each effect:
- Flanger+Dist: Rate
- Chorus: Depth
- Phaser: Depth
- Delay: Wet Amount
- Reverb: Wet Amount
Touch the panel to access the FX Settings stack.

## Dashboard - Controls

Top Knob: Control the value of the X Modulator.
Bottom Knob: Control the value of the Y Modulator.

Home: Cycle between the X/Y Modulator Screen and the Dashboard.
Layer: Access the Grid Keyboard, and then cycle between the Grid Keyboard and the XY Modulator Screen.
Left Arrow: Open the nanobox Config screen.
Right Arrow: Open the Preset Config screen.

# Make Some Music

To make sound with nanobox, you trigger notes via the Grid Keyboard screen or a MIDI controller. You can tweak the sound in real time by adjusting parameters and by controlling the X & Y Modulators from either the Dashboard or the X/Y Modulator screen. All sound is sent to the Line Out jack.

## Grid Keyboard

The Grid Keyboard allows you to play notes that are always on key. Each row in the grid corresponds to one octave. You can choose which scale to use. Push the Layer button from the Dashboard or the XY Modulator Screen to access the Grid Keyboard.

Note Grid: Touch a cell in the note grid to trigger that note. If Hold is enabled, the note will play until you touch it again. Otherwise, the note will end when you stop touching it.
Playing Note: Currently playing notes are highlighted red. Touch a playing note to clear it.
Octave Label: The first and last cell in each row is labeled with the octave mapped to that row.
Octave Selectors: Touch the left and right chevrons to scroll the grid one octave.
Hold Button: When inactive (gray), notes only play while you are touching them. When active (black with red outline), notes continue to play until you touch them a second time.

### Grid Keyboard - Keyboard Config

Scale: The scale imposed by the keyboard grid. Options: Chromatic, Major, Major Pent, Minor, Minor Pent, Minor Blues, Raga Bhairav, Raga Todi, Gypsy, Arabian, Egyptian, Miyakobushi, Ryukyu, Wholetone, Diminish, Harmonic Minor, Mel Minor, Dorian, Phrygian, Lydian, Mixolydian, Aeolian, Locrian. Not a modulation target.
Root Note: A, A#, B, C, C#, D, D#, E, F, F#, G, G#. Not a modulation target.

## MIDI Controller

Nanobox is designed to work with your MIDI controller to trigger notes and control the sound. Keyboard and pad controllers can trigger notes, while knobs and sliders can be mapped to control parameters. Standard MIDI modulators like velocity, after touch and mod wheel are supported.

Hardware Connection: Connect your MIDI controller to the TRS MIDI In jack. The system will automatically recognize if the MIDI controller uses Type A or Type B TRS MIDI connections. Use the included adapter for MIDI 5 Pin DIN. Nanobox does not support USB MIDI.

MIDI Channel: From the Dashboard, push the Left Arrow button to access the nanobox Config screen. Set the value of the MIDI In Parameter to the channel used by your MIDI controller.

NOTE: The Hold button on the Grid Keyboard does not impact notes received via MIDI. The Grid Keyboard does not show notes that have been triggered by MIDI.

## XY Modulator Pad

The XY Modulator Pad allows you to use touch gestures and knobs to control the X and Y modulation sources. Each factory preset is configured to map the X and Y modulators to one or more parameters that will add interesting dimension to the sound. The XY pad only affects sounds that are currently playing.

XY Pad: Touch the screen to move the X and Y modulator values. Tap for momentary change, or hold and drag for longer sweeping changes. Drag left/right to control X, up/down to control Y.
Fallback Position: When you release your finger from a drag motion, X and Y values jump to the Fallback position (white + icon). Turn knobs to adjust.
Current Position: Red ball indicates current position of X and Y modulators.
0,0 Point: Gray + icon represents the point where X and Y are both zero.

Example preset: 095Windy — X modulator mapped to WT1 Position, Filt1 Resonance and Cutoff, and LFO1 Rate. Y modulator mapped to WT2 Position, Filt2 Center Frequency and Q, and LFO2 Rate.

Top Knob: Control the value of the X Modulator and set the fallback position.
Bottom Knob: Control the value of the Y Modulator and set the fallback position.

# Configure the Sound Generation

Fireball uses wavetable synthesis to generate sounds ranging from breathy winds to plucky marimbas, and from bright bells to deep basses. At the heart of the sound engine are two wavetable oscillators and one waveform oscillator. Each preset uses a different combination of WAV files, oscillators and audio settings to generate a unique sound.

You can further customize the sound via 2 filters, 2 envelopes, 2 LFOs, 1 modulation sequencer and 2 effects engines accessed from the Dashboard. All settings are saved on the microSD card.

You can also use the fireball effects on a live audio input signal. Connect the audio signal to the Line In and this signal will be added to the inputs to the effects engine.

## Wavetable Oscillators

Two of the three oscillators are wavetable oscillators. A wavetable oscillator uses a WAV file containing a wavetable. Each cycle of the wavetable is like a single frame of a film. Within each cycle, there are 2048 samples. The nanobox fireball comes with 103 wavetables paired in different combinations to create 121 presets. You can add your own wavetables to the microSD card. Compatible wavetables must contain 2048 samples per cycle and 256 cycles.

Touch a wavetable oscillator graph on the Dashboard to access this screen. Push Layer to cycle through the Oscillators.

Parameters:
- Pitch: How many semitones up or down to shift the pitch. Range: -24.00 to +24.00 semitones. Modulation target: Yes.
- Level: The relative audio level of this waveform. Range: 0-100%. Modulation target: Yes.
- Wavetable: The wavetable file on the microSD card. Over 100 wavetables included. Push the Right Arrow button to select a different file. Compatible with 2048 samples per cycle and 256 cycles. Modulation target: No.
- Position: Sets the cycle of the wave that will be looped. Use modulation to vary the position. Range: 0 to 255 cycles. Modulation target: Yes.

## WAV File Selection Screen

Choose the WAV File from the microSD card that has the wavetable to be used for this oscillator. To get here, touch the WAV File graph at the top of the Wavetable Oscillator screen, or push Right Arrow when the File parameter is selected.

microSD File System Tree: Turn a knob to scroll through the list of files and directories.
Previous Directory (^) Button: Touch to navigate back a directory in the file tree.
Load Button: Touch to load a selected directory into the file tree or to load the selected file into the Wavetable Oscillator.

Top Knob: Scroll through the file list.
Bottom Knob: Scroll through the file list.

## Waveform Oscillator

The third oscillator is a waveform oscillator that can add depth to the sound. Touch a wavetable oscillator graph on the Dashboard, then push the Layer button to cycle through the oscillators to reach this screen.

Parameters:
- Pitch: Number of semitones to shift the pitch. Range: -24.00 to +24.00 semitones. Modulation target: Yes.
- Level: Relative audio level of the oscillator waveform. Range: 0 to 100%. Modulation target: Yes.
- Waveform: Shape of the oscillation. Options: Saw, Triangle, Square, Sine, Noise. Modulation target: No.
- Pulse Width: Only applies when Square is selected. The portion of the wave that will have a high signal. 50% = high half the time and low half the time. 75% = high 3/4 of the time and low 1/4 of the time. Range: 0 to 100%. Modulation target: Yes.

# Tweak the Sound

Once you have set up the oscillators to generate the sound, you can use the audio control features to tweak and enhance the sound. The nanobox fireball audio controls include two filters, two envelopes, two LFO modulators, one bar sequencer modulator, and two effect slots.

## Signal Path

The audio engine adds the outputs of the three oscillators together, then applies ENV1 to shape the level of the signal. The resulting signal is sent to the filters.

Serial Mode (Filter 2): Signal runs through Filter 1, then the result runs through Filter 2.
Parallel Mode (Filter 2): The output of the envelope is sent to each filter independently, and the outputs are added together.

The result is combined with the Line In signal before being processed by FX1 followed by FX2. The output of FX2 is adjusted by the master volume. The compressor is then applied. The resulting signal is sent to the Line Out.

Signal chain: WT1 + WT2 + OSC → ENV1 → Filters → + Line In → FX1 → FX2 → Master Volume → Compressor → Line Out

## Filters

Filters control the frequency of the audio signal. The two filters may be applied in series or parallel. Filter parameters vary based on the Type selected. Touch FILT on the dashboard to access the Filter screen, then push Layer to cycle through the Filter stack.

Filter Types:
- Notch: Filters out frequencies within the range around the Center Point defined by the width.
- Band Pass: Filters out frequencies outside the range around the Center Point defined by the width.
- High Pass: Filters out frequencies below the cutoff point.
- Low Pass: Filters out frequencies above the cutoff point.

Low Pass and High Pass Parameters:
- Cutoff: Frequency where the filter begins to attenuate. Range: 20 Hz to 20.4 kHz. Modulation target: Yes.
- Resonance: Boost given to signal near cutoff frequency. Range: 0 to 100%. Modulation target: Yes.
- Filter: On/Off. Modulation target: No.
- Mode (Filter 2 only): Serial or Parallel. Modulation target: No.

Notch Parameters:
- Center Freq: Frequency at the middle of the notch. Range: 20 Hz to 20.4 kHz. Modulation target: Yes.
- Q: Level of attenuation at and around center frequency. Range: 0 to 100%. Modulation target: Yes.
- Filter: On/Off. Modulation target: No.
- Mode (Filter 2 only): Serial or Parallel. Modulation target: No.

Band Pass Parameters:
- Center Freq: Frequency at the middle of the band. Range: 20 Hz to 20.4 kHz. Modulation target: Yes.
- Width: Width of the frequency range. Range: 0 to 100%. Modulation target: Yes.
- Filter: On/Off. Modulation target: No.
- Mode (Filter 2 only): Serial or Parallel. Modulation target: No.

## Envelopes

Two envelopes are available. ENV1 is applied to the combined output of the three oscillators before the signal is sent to the filters. Either envelope can also be used as a modulation source for parameters with modulation slots. Touch ENV on the Dashboard to access envelopes. Use Layer to cycle through them.

Parameters:
- Attack: Time for sound to reach its loudest level. Range: 0 to 100%. Modulation target: Yes.
- Decay: Time for sound to go from initial peak to sustain level. Range: 0 to 100%. Modulation target: Yes.
- Sustain: Volume level maintained when holding a note. Range: 0 to 100%. Modulation target: No.
- Release: How long the note continues to play and fade out when released. Range: 0 to 100%. Modulation target: Yes.
- Velocity: Impact of MIDI Velocity on overall envelope level. Range: -100 to +100%. Modulation target: No.

## Low Frequency Oscillators

The LFOs are internal modulators for adding life and variety to the sound. Two LFOs are available, each with a selectable waveform. Push LFO/SEQ on the Dashboard to configure. Use Layer to cycle through the stack.

Parameters:
- Waveform: Shape of the LFO wave. Options: Saw, Rev Saw, Triangle, Pos Tri, Sine, Pos Sine, Square, Pos Square, Random. Modulation target: No.
- Rate: LFO frequency, approximately 0.1 Hz to 12 Hz (0.0% to 100.0%). When Beat Sync is On, rate is specified in beats/measures: 8, 4, 2, 1, 1/2, 1/2 T, 1/4, 1/4 T, 1/8, 1/8 T, 1/16, 1/16 T, 1/32, 1/32 T, 1/64 bars. Modulation target: Yes.
- Depth: Amplitude of the oscillating wave. Set to 0 to disable. Range: 0 to 100%. Modulation target: Yes.
- Trig: When active, LFO restarts each time pad is triggered. On/Off. Modulation target: No.
- Beat Sync: Controls rate parameter operation. When On, wave cycle is synchronized with the clock. On/Off. Modulation target: No.

## Bar Sequence Modulator

The SEQ is a bar sequencer used for internal modulation. You can set the number of steps and step length, and turn on Quantize to snap values to pitch frequencies. Push LFO/SEQ on the Dashboard, then use Layer to cycle to the bar Sequencer.

Sequencer: Tap or drag to set the value for each step. You can also use the knobs.
Zero Line: Drag along the zero line to reset values to zero.
Playback Position: White rectangle highlights the playback position.
Edit Position: Light gray bar indicates the editor position.

Parameters:
- Step Len: Length of each step. Options: 1/64, 1/32T, 1/32, 1/16T, 1/16, 1/8T, 1/8, 1/4T, 1/4, 1/2T, 1/2, 1 bar, 2 bar (T=Triplet). Modulation target: No.
- Steps: Number of steps in the sequence. Range: 2 to 32. Modulation target: No.
- Key Trig: When On, sequencer restarts with each new note. When Off, plays constantly and resumes at current position. Modulation target: No.
- Quantize: When On, sequencer levels are quantized to 12 distinct values (plus off), allowing precise semitones in pitch modulation. On/Off. Modulation target: No.

## Effects

Fireball has two effects slots. FX1 options: Flanger+Dist, Chorus, Phaser. FX2 options: Delay, Reverb. The audio engine sends the output of the filters to FX1, which feeds into FX2. Master volume and compressor are applied to the output of FX2. Touch FX on the Dashboard to access. Use Layer to cycle between FX1 and FX2.

Flanger+Dist Parameters:
- Flng Depth: Depth of flanger effect. Range: 0.0 to 100.0%. Modulation target: No.
- Rate: Rate of flanger. Range: 0.0 to 100.0%. Modulation target: Yes.
- Feedback: Feedback in flanger effect. Range: 0.0 to 100.0%. Modulation target: No.
- Dist Depth: Depth of distortion. Range: 0.0 to 100.0%. Modulation target: No.

Chorus Parameters:
- Depth: Depth of chorus. Range: 0.0 to 100.0%. Modulation target: Yes.
- Rate: Rate of chorus. Range: 0.0 to 100.0%. Modulation target: No.

Phaser Parameters:
- Depth: Depth of phaser. Range: 0.0 to 100.0%. Modulation target: No.
- Rate: Rate of phaser. Range: 0.0 to 100.0%. Modulation target: Yes.
- Feedback: Feedback in phaser. Range: -100 to 100%. Modulation target: No.

Reverb Parameters:
- Wet Amount: Wet signal level (100% dry always sent). Range: 0.0 to 100.0%. Modulation target: Yes.
- Decay: Reverberation ring out amount. Range: 0 to 100%. Modulation target: Yes.
- Pre-Delay: Time between dry sound and onset of early reflections. Range: 0 to 100%. Modulation target: Yes.
- Damping: Dampening applied to reverb. Higher values = shorter reverb. Range: 0 to 100%. Modulation target: Yes.

Delay Parameters:
- Wet Amount: Wet signal level. Range: 0.0 to 100.0%. Modulation target: Yes.
- Feedback: Regeneration/echo amount. 0% = single echo. Range: 0.0 to 100.0%. Modulation target: Yes.
- Filter: Turn on to filter the delay. Modulation target: No.
- Cutoff: Center frequency for band pass filter (when Filter is On). Range: 20 Hz to 20.4 kHz. Modulation target: Yes.
- Freq Width: Width of frequency range (when Filter is On). Range: 0.0 to 100.0%. Modulation target: No.
- Ping Pong: Echoes alternate sides (On) or same in both channels (Off). Modulation target: No.
- Beat Sync: When On, delay measured in musical time. When Off, controlled as percentage. Modulation target: No.
- Delay Len: When Beat Sync On: 1/64, 1/32, 1/16, 1/8T, 1/16D, 1/8, 1/4T, 1/8D, 1/4, 1/2T, 1/2, 1 bar (T=Triplet, D=Dotted). When Beat Sync Off: 0% to 100% (100% = 4 seconds). Modulation target: Yes.

### Effects and Live Input

Nanobox will add the audio signal from the Line In to the signal sent to the effects engine.

## Parameter Modulation

Any parameter with modulation slots (red boxes along the right side) can be controlled using internal or external modulation. Envelopes, LFOs and SEQ automate modulation. X and Y modulators, standard MIDI modulators and MIDI CCs control parameters in real time.

Modulation Slots: Three red boxes on the right side of a parameter row. Black-filled boxes are empty; red-filled boxes are in use. Push Right Arrow to configure sources.

Target Parameter: The name of the element and parameter being modulated is displayed at the top of the Modulation Parameters screen.

MIDI Learn: With a Source row selected, touch Learn to enable MIDI Learn mode (button turns black with red border). Use a MIDI controller to map the CC to the slot. Once mapped, the Learn button turns gray. Touch Learn again or leave the screen to disable without mapping.

Modulation Settings: Each slot has a Source and Amount row. Turn the bottom knob or use Learn to select a source. Set Amount to adjust the modulation impact.

Available modulation sources include: Velocity, Pressure, Key, Mod Wheel, MIDI CCs, X Modulator, Y Modulator, ENV1, ENV2, LFO1, LFO2, SEQ.

NOTE: Parameter list numbers will not change as values are modulated. Dashboard gauges will move to reflect modulated values.

# MIDI Controllers

You can use your MIDI controller to play notes, synchronize with a clock, modulate parameters and control the X and Y modulators. Nanobox can also pass the MIDI signal through to another MIDI device.

## Set Up MIDI

1. Connect your MIDI controller to nanobox directly using a TRS MIDI connection or via the TRS to MIDI 5 Pin DIN adapter included. Nanobox does not support MIDI over USB.
2. From the Dashboard, push the Left Arrow button to access the nanobox Config screen.
3. Set the MIDI In Parameter to the MIDI channel used by your controller. This channel is used for notes, CCs, clock sync, and X/Y modulators.
4. To pass MIDI through, connect MIDI out to another MIDI device.

## MIDI Clock Synchronization

Nanobox fireball uses a clock to synchronize the LFOs, SEQ and Effects. Set tempo internally via BPM parameter on the Preset Config screen (Right Arrow from Dashboard). If fireball receives a clock signal over MIDI or Clock In, it will follow that signal.

Clock priority:
1. Clock In
2. MIDI Clock
3. Internal BPM from the Preset Config screen

## Parameter Modulation via MIDI

Use standard MIDI signals to modulate a parameter: Velocity, Pressure, Key, and Mod Wheel. Use the Learn button to map a MIDI CC to a modulation slot. See Parameter Modulation section for details on applying MIDI to modulation slots.

## Control the X and Y Modulators via MIDI

The X and Y modulators can be controlled via MIDI:
1. From the Dashboard, push the Left Arrow button to access the nanobox Config screen.
2. Choose a CC number for the X Mod and Y Mod parameters. Nanobox will respond to these CC numbers on the channel specified by the MIDI In parameter.

## Synchronizing with the Clock In

You can use an analog clock pulse to synchronize nanobox with other gear. Nanobox expects a 4 PPQ (pulses per quarter note) pulse.

Clock priority:
1. Clock In
2. MIDI Clock
3. Internal BPM from the Preset Config screen

Check the 1010music forum for the latest firmware release.
1. Download the NANOFIRE.BIN file from the forum. Registration (free) is required for access to downloads.
2. Replace the NANOFIRE.BIN file on the microSD card with the downloaded file. Note: the filename must be exactly nanolem.bin.

# Nanobox Configuration

From the Dashboard, push the Left Arrow button to access the nanobox Config screen. Settings here apply across all presets and are automatically saved with every change.

Parameters:
- Brightness: Touchscreen brightness. Range: 0 to 100%.
- Volume: Audio output volume. Range: 0 to 100%.
- Compressor: When On, audio compressor is applied to line out signal.
- MIDI In: MIDI channel to control fireball. Options: None, Ch 1 to 16, Omni.
- X Mod: MIDI CC to control Macro X modulation source (same as top knob on Dashboard and left/right on X/Y Modulation grid). Options: None, CC000 through CC127.
- Y Mod: MIDI CC to control Macro Y modulation source (same as bottom knob on Dashboard and up/down on X/Y Modulation screen). Options: None, CC000 through CC127.
- Line Thru: Amount of Line Input signal added to signal sent through FX engine. Range: 0% to 100%.
- Line Input: When set to Mono, only uses signal on left channel. Options: Stereo, Mono.

# Preset Configuration

From the Dashboard, push the Right Arrow button to access the Preset Config screen. Settings here apply to the current preset and are only saved when you save the preset.

Parameters:
- BPM: Clock tempo. Range: 40 to 250. Modulation target: No.
- Osc Reset: If On, with each new note the oscillator starts the wave at 0. If Off, the oscillator picks up from before. Does not apply to LFOs. Options: On, Off. Modulation target: No.
- Bend Range: Number of semitones covered by full spread of MIDI Pitch Bend. Range: 1 to 12. Modulation target: No.
