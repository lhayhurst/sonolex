# Introduction

The Fireface UCX II is a unique audio system capable of transferring analog and digital audio data directly to Windows and Mac computers. Plug and Play technology guarantees simple installation. Drivers are available for Windows 7 to 11 (Intel, ARM), Mac OS X x86 (Intel) and macOS (Intel, Mx).

# Package Contents

- Fireface UCX II
- Cable USB 2.0, 1.8 m (6 ft)
- Optical cable (TOSLINK), 2 m (6.6 ft)
- B0968 Digital breakout cable (XLR/RCA)
- External switched power supply, lockable connector, DC 12 V 24 W
- Power cord

# System Requirements

- Windows 7 or up, Intel Mac OS X (10.12 or up)
- 1 x USB 2.0 or USB 3.0 port
- Computer with at least Intel Core i3 CPU

# Key Features and Characteristics

- All settings can be changed in real-time
- Buffer sizes/latencies from 48 up to 8192 samples selectable
- 4 channels 96 kHz/24 bit Record/Playback via ADAT optical (S/MUX)
- 2 channels 192 kHz/24 bit Record/Playback via ADAT optical (S/MUX4)
- Clock modes slave and master
- Automatic and intelligent master/slave clock control
- Unsurpassed Bitclock PLL (audio synchronization) in ADAT mode
- SteadyClock FS: Jitter-immune, super-stable digital clock
- DDS technology for free setting of the sample rate
- SyncAlign guarantees sample aligned and never swapping channels
- SyncCheck tests and reports the synchronization status of input signals
- TotalMix for latency-free submixes and perfect ASIO Direct Monitoring
- TotalMix: 800 channel mixer with 46 bit internal resolution
- TotalMix FX: 3-band EQ, Low Cut, Reverb, Echo, Compressor, Expander, Auto Level
- TotalMix FX Room EQ: 9-band PEQ with Delay and Volume Calibration
- 1 x MIDI I/O, 16 channels high-speed Low-Jitter MIDI
- 1 x Hi-power low impedance headphone output
- DIGICheck DSP: Level meter in hardware, peak- and RMS calculation

# Front Panel

The front of the Fireface UCX II features two instrument and microphone inputs, a stereo headphone output, a rotary encoder with push functionality, four buttons, a graphical colour display and two status LEDs.

The Neutrik combo sockets of the two Mic/Line inputs provide XLR and 6.3 mm / 1/4" TRS connection with LEDs for phantom power (48V) indication.

Inputs 3/4 (INST/LINE) accept both a balanced line signal and an unbalanced instrument signal via 1/4" TRS plug.

Analog outputs 7 and 8 feed the headphones output (Phones). This low impedance output is able to drive headphones at higher levels undistorted.

The four keys and encoder, the high-resolution colour display, and menu structure enable complete device configuration without a computer.

Digital State: The main screen shows current sample rate and state of all digital input signals. WCK, SPDIF, AES and ADAT indicate a valid input signal. SyncCheck indicates if an input is locked but not synchronous (field will flash). The field USB changes to CC when in Class Compliant mode.

State MIDI: Between ADAT and USB two yellow lines indicate incoming and outgoing MIDI data.

# Rear Panel

The rear panel features 4 analog inputs and 6 analog outputs, power socket, USB, DURec (USB-A), word clock, MIDI I/O, ADAT I/O, and a connector for the included breakout cable D-sub to XLR/RCA (SPDIF/AES I/O).

- Balanced Line Level Inputs: 4 balanced analog inputs via 6.3 mm stereo TRS connectors
- Balanced Line Level Outputs: 6 balanced analog outputs via 6.3 mm stereo TRS
- AES/EBU & SPDIF: XLR via breakout cable supporting both SPDIF coaxial and AES/EBU
- Word: BNC, can be set as word clock output or input, input terminatable with 75 Ohms internally
- ADAT I/O: TOSLINK, standard 8-channel ADAT optical port, can also be used as optical SPDIF
- DURec (Remote): USB-A connector for USB stick/hard drive for direct recording/playback, or for optional ARC USB remote
- USB 2.0: USB socket for computer connection, compatible with USB 3.0
- MIDI I/O: Two 5-pin DIN connectors
- Hook: For securing loose cables
- Kensington Lock: Remove hook to access security hole
- Power: 12 V DC switched power supply (100-240 V AC), lockable turn-to-lock connector, center pin +, outer pin GND

# Menu and Navigation

The Fireface UCX II has a simple 1-button operation. Pressing the VALUE encoder switches between adjusting the parameter (horizontal) and moving vertically through the menu.

Default display is the Global Level Meter screen showing current signal levels for all I/Os. Pressing the encoder for half a second shows only analog I/Os (Analog Level Meter screen).

The display also shows: current sample rate, clock mode and Lock/Sync status, MIDI I/O activity, USB/CC mode, current output volume setting, and DSP meter load.

Turning the knob displays the volume screen. Pressing toggles between Main Out and Phones.

Quick select buttons: MIC/GAIN, REC/PLAY, CHAN/MIX, SETUP/REV.

# Special Options

Found in SETUP/REV - Options - Hardware/Diagnosis:

Standalone ARC options (for optional ARC USB connected directly to UCX II):
- Standalone ARC Volume: Deactivates all keys, only encoder works for Main Volume
- Standalone ARC 1 s op: Each key must be pressed for one second (safety function)
- Standalone ARC normal: Normal ARC USB operation

Lock Keys: OFF, KEYS, ALL. Press SETUP/REV for 2 seconds to unlock.

Remap Keys: OFF, ON. Allows assigning 28 different functions/actions to the four quick select buttons for offline/stand-alone operation. In online mode with TotalMix FX, up to 47 functions available. Available functions: Default, Meter, Setup 1-6, DIM, Recall, Mute Enable, Main Mono, Main Mute, Main Out Low Cut, Main Out EQ, Main Out Dynamics, Main Out AutoLevel, Phones Mute, Phones Low Cut, Phones EQ, Phones Dynamics, Phones AutoLevel, Reverb enable, Echo enable, Record, Play/Pause, Stop, Previous, Next (DURec functions).

Online mode: If TotalMix is selected, buttons call up actions assigned in TotalMix FX ARC & Key Commands dialog (buttons labelled A through D).

Level Meters: All or Analog display selection.
Scroll Type: cw up or cw down for encoder scroll direction.

# Driver and Firmware Installation - Windows

Recommended to install drivers before connecting the unit. Download latest drivers from http://rme.to/downloads. Run rmeinstaller.exe. Connect UCX II via USB 2 cable. Windows detects as Fireface UCX II and installs drivers automatically. After reboot, TotalMix FX and Settings dialog icons appear in notification area.

Driver updates do not require removing existing drivers.

For uninstalling: Start rmeinstaller.exe and select 'Uninstall the last installed driver package'.

Firmware Update: Download Flash Update Tool from http://rme.to/usbe. Run fut.exe, press Update if needed. After update, power cycle the unit. Safety BIOS protects against failed updates.

# Driver and Firmware Installation - Mac OS X

Download latest drivers from http://rme.to/usbe. Install via Fireface USB xxx.pkg or Fireface USB DK xxx.pkg. Programs Totalmix and Fireface USB Settings are copied to Applications folder. Reboot after installation.

RME offers both Kernel Extension and DriverKit drivers. Refer to included documentation for installation details specific to your architecture and macOS version.

Firmware Update: Start Fireface USB Flash program. Update and power cycle the unit. Option 'Flash All' forces update of all firmware parts. Secure BIOS Technology protects against failed updates.

## Settings Dialog - Windows

Configuration via Settings dialog opened from the system tray (fire/hammer symbol). TotalMix FX opened from DSP FX symbol.

Settings include: Latency, DSP operation, digital I/O configuration, sample rate, synchronization behaviour, input/output state. Changes applied immediately.

About tab shows driver/firmware version and offers:
- Lock Registry: Password-protects settings stored in registry
- Enable MMCSS for ASIO: Higher priority for ASIO driver
- Sort ASIO Devices: Changes order of ASIO channels with multiple interfaces

## Buffer Size and Output Format

Buffer Size determines latency between incoming/outgoing ASIO and WDM data.

Errors display indicates USB transmission errors, reset on playback/record start.

Word Clock Output - Single Speed: Output stays in 32-48 kHz range even at higher sample rates.

Optical Output: TOSLINK operates as ADAT or SPDIF. ADAT includes channels ADAT 1-8. SPDIF includes channels SPDIF opt. L/R. In SPDIF mode Channel Status is fixed to Consumer.

SPDIF Output: Coaxial (RCA) can be Professional or Consumer Channel Status.

Options:
- DSP - EQ+D for Record: Switches EQ and Dynamics into recording path
- TMS: Activates Channel Status and Track Marker transmission on AES/SPDIF
- Word Clock In Termination: 75 Ohm internal termination
- Word Clock Output: Switches BNC to output mode
- WDM Devices: Reduce number for performance

## Clock Mode and Pitch

Sample Rate: Sets current sample rate centrally for all WDM devices.

Clock Source: Internal (Master) or input signals (Word, SPDIF, AES, ADAT). AutoSync mode scans for valid signal, falls back to internal clock if none available.

Input Status: Shows Lock/No Lock/Sync state and detected sample frequency for each input.

Pitch: Based on DDS (Direct Digital Synthesizer). Includes video pull up/pull down frequencies (0.1% and 4%) and a fader for +/- 5% range in 1 Hz steps. Requires Master clock mode. Coarse adjustment: 50 Hz steps (mouse click). Fine: 1 Hz steps (cursor keys). Reset: Ctrl + left click.

## WDM Devices

Configuration and status of WDM devices. Number represents both record and playback stereo devices. WDM Loudspeaker (Analog 1+2) can operate as stereo or up to 8-channel device for surround playback. Configure via Control Panel/Sound/Playback/Loudspeaker/Configure for 7.1 Surround.

## Settings Dialog - Mac OS X

Start Fireface USB Settings program. Use 'Properties For' drop-down to select unit.

Input Options:
- Word Clock Input: Switches BNC to input mode
- Word Clock Termination: Internal 75 Ohm termination
- DSP Record EQ+D: EQ and Dynamics in recording path

Output Options:
- SPDIF Format: Professional or Consumer
- Optical Out: ADAT or SPDIF

Clock Options:
- Word Clock I/O Single Speed: Output stays 32-48 kHz range. Input: when not checked, follows external rate directly (Follow Clock)
- Sample Rate: Current sample rate setting
- Clock Source: Internal or input signals with AutoSync

Input Status: Lock/Sync state and detected frequency per input.

Safety Offset: Short (lower latency, risk of clicks) or Large (maximum security).

Channel Limit (DriverKit only): USB performance optimization by transmitting fewer channels (8, 16, 32).

Diagnostics (DriverKit only): Counters for USB error states.

# Operation and Playback - Windows

Select Fireface UCX II as output device in audio application. Recommend switching off system sounds. Increasing buffer sizes prevents audio breakup but increases latency.

Since Windows Vista, sample rate set globally via Settings dialog, not by application. Wait at least 5 seconds after changing sample rate before starting playback.

DVD Playback (AC-3/DTS): Set sample rate to 48 kHz. Select UCX II output as Default. DVD software shows SPDIF Out option for non-decoded digital multichannel stream. Multichannel decoded playback uses WDM Loudspeaker device.

Surround channel assignment: 1-Left, 2-Right, 3-Center, 4-LFE, 5-SL, 6-SR.

# Channel Count at Different Sample Rates

ADAT channels reduce via Sample Multiplexing (S/MUX) at higher rates:

Single Speed (44.1/48 kHz): 8 analog + SPDIF + AES + 8 ADAT = 20 channels
Double Speed (88.2/96 kHz): 8 analog + SPDIF + AES + 4 ADAT = 16 channels
Quad Speed (176.4/192 kHz): 8 analog + SPDIF + AES + 2 ADAT = 14 channels

Under WDM, unavailable devices vanish automatically. Under Core Audio (Mac), channels stay present but become partly inactive (no reboot-free change). Under ASIO, channel count changes may require I/O list reset in audio software.

# Multi-client Operation

Multiple programs can be used simultaneously. ASIO and WDM can share playback channels (WDM uses real-time sample rate conversion). All active ASIO software must use the same sample rate. Inputs can be used by unlimited WDM and ASIO software simultaneously. TotalMix allows any output routing for multiple software on same hardware outputs. DIGICheck operates as special ASIO host that can analyze playback data from any software.

# Analog Recording

Select Fireface UCX II Analog (x+x) as recording device. Rear input sensitivity adjustable in TotalMix (Input Channel Settings, Level: +13 dBu / +19 dBu, plus Gain). Front input levels adjustable via TotalMix or directly at the unit (MIC/GAIN key + encoder). Aim for peak levels around -3 dB.

Zero-latency monitoring via TotalMix FX. ASIO Direct Monitoring supported for automated monitoring during punch-in recording.

# Digital Recording

Digital interfaces require valid input signal to record. I/O signal status display shows sample frequency, lock and sync status for every input. If no sample frequency recognized, displays 'No Lock'.

# Clock Modes and Synchronization

All devices must be either Master or Slave. Only one master allowed in a digital system.

AutoSync: Constantly scans digital inputs for valid signal. Switches from internal clock to extracted clock when valid signal found. Falls back to internal clock if reference fails.

SyncCheck: Indicates Lock (valid signal), No Lock, or Sync (valid and synchronous) for each input (Word Clock, SPDIF, ADAT, AES). Provides easy verification that all digital devices are properly configured.

Clock Source: Preferred input can be defined. System scans other inputs if preferred source fails.

# ASIO Operation

Select ASIO Fireface USB as audio I/O device. Supports ASIO Direct Monitoring (ADM). MIDI I/Os usable with MME MIDI and DirectMusic MIDI.

ASIO channel count at different sample rates:
- Single Speed: Analog 1-8, SPDIF L/R, AES L/R, ADAT 1-8
- Double Speed: Analog 1-8, SPDIF L/R, AES L/R, ADAT 1-4
- Quad Speed: Analog 1-8, SPDIF L/R, AES L/R, ADAT 1-2

Known problems: Insufficient CPU/USB bandwidth causes dropouts (increase buffer size). Incorrect synchronization causes noise (all devices must show Sync, not just Lock). Multiple Firefaces must be in sync. ADM panorama issues may occur with some programs. For MIDI drift, try 'Use System Timestamp' option in DAW.

# Using Multiple Fireface UCX II Units

Driver supports up to three Fireface UCX II or combination of supported interfaces. All units must be in sync via word clock or synchronized signals. If one is Master, others must be AutoSync/Slave. Under ASIO, all units present as one. TotalMix is per-unit (no global mixer across units). Multiple units may cause computer resource issues.

# DIGICheck

Unique utility for testing, measuring and analysing digital audio streams. Operates as multi-client ASIO host. Available functions:
- Level Meter: 24-bit resolution, 2/8/20 channels, peak/RMS, over-detection, phase correlation, K-System
- Hardware Level Meter: Input, Playback, Output with near zero CPU load
- Spectral Analyser: 10/20/30-band, 192 kHz capable
- Vector Audio Scope: Goniometer with oscilloscope afterglow
- Totalyser: Combined Spectral Analyser, Level Meter, Vector Audio Scope
- Surround Audio Scope: Professional surround level meter with ITU weighting
- ITU1770/EBU R128 Meter: Standardized loudness measurements
- Bit Statistics & Noise: True resolution, errors, DC offset, SNR
- Channel Status Display: SPDIF/AES/EBU Channel Status analysis
- Global Record: Long-term recording at lowest system load

DIGICheck NG (Mac) adds: Program Meters, Frequency Measurement, Oscilloscope, Spectroscope.

Free software, works only with RME interfaces. Download from www.rme-audio.com.

# Analog Inputs



## Line Rear (Inputs 5-8)

Four balanced Line inputs as 1/4" TRS jacks. Servo balanced design handles unbalanced and balanced correctly. When using unbalanced cables with TRS jacks, connect ring to ground.

Reference levels:
- +19 dBu: 0 dBFS @ +19 dBu, with 12 dB max gain: 0 dBFS @ +7 dBu
- +13 dBu: 0 dBFS @ +13 dBu, with 12 dB max gain: 0 dBFS @ +1 dBu

A reference level of +4 dBu can be set by using +13 dBu and adding 9 dB of gain.

## Microphone / Line Front (Inputs 1-2)

Two balanced microphone inputs via XLR/TRS combo jacks. Digitally controlled gain 0 to 75 dB in 1 dB steps. Soft switching 48V phantom power per channel. Up to +18 dBu input level on front XLR as line input.

TRS jacks of combo jacks are free of phantom power, compatible with unbalanced sources, with fixed 6 dB attenuation. Maximum input level +24 dBu balanced/unbalanced.

Channels 1-4 feature AutoSet automatic overload protection maintaining 6 dB headroom. Levels higher than -6 dBFS permanently reduce gain. AutoSet operates ganged on stereo channels. Toggle via TM FX or encoder push. AS label changes from black to blue when gain is reduced.

## Instrument / Line Front (Inputs 3-4)

Exceptionally flexible inputs with multiple gain and impedance options.

Line mode: Balanced 1/4" TRS, servo balanced design. Identical specs to rear inputs 5-8.

Adjustable Input Gain: 0 to 12 dB in 0.5 dB steps via TotalMix or front encoder.

Two reference levels (+13 dBu, +19 dBu) plus 12 dB gain handle levels from +1 dBu to +19 dBu.

Instrument mode: Via Inst option in TotalMix channel settings, input impedance changes from 10 kOhm to 1 MOhm (Hi-Z). Input sensitivity rises by 6 dB. Operates unbalanced only (use TS jacks, not TRS).

# Analog Outputs



## Line Out (Outputs 1-6)

Short circuit protected, low impedance outputs as 1/4" TRS jacks. Servo balanced design.

Reference levels:
- +19 dBu (equivalent to older RME Hi Gain/Lo Gain with 15 dB headroom)
- +13 dBu (equivalent to older +4 dBu with 9 dB headroom)
- +4 dBu (equivalent to older -10 dBV with 12 dB headroom)

## Headphones / Line Out (Outputs 7-8)

Front 1/4" TRS stereo jack. Same converters as other Line outputs. Two hardware reference levels: High (+19 dBu) and Low (+4 dBu). Output impedance: 1 Ohm. Volume controlled via TotalMix or front encoder. Can be used as unbalanced line outputs with adapter. Pin assignment: tip = left, ring = right.

## DC-Coupled Outputs (CV/Gate)

All eight analog outputs are DC-coupled, allowing level-linear operation down to 0 Hz. Useful for measurement technology and controlling analog synthesizers via Control Voltage (CV/Gate).

DA converters have very low DC drift for reliable, reproducible CV output. TotalMix fully supports DC via fader and level meter.

Voltage Ranges (unbalanced, unloaded):
- Line Out 1-6: +19 dBu = +9.5V, +13 dBu = +4.75V, +4 dBu = +1.7V
- Phones 7/8: High (+19 dBu) = +9.5V, Low (+4 dBu) = +1.7V

Note: TotalMix level meters show DC 3 dB higher by default. Disable Settings > Level Meters > RMS +3 dB to correct.

Avoid negative output voltages for CV inputs. Watch for phase inversion in TotalMix.

# Digital Connections



## ADAT

ADAT optical input fully compatible with all ADAT outputs. Unsurpassed Bitclock PLL prevents clicks and dropouts in varispeed. Standard TOSLINK cable required.

ADAT In: 8 channels at Single Speed, 4 at Double Speed (S/MUX), 2 at Quad Speed (S/MUX4). Automatically recognizes 2-channel SPDIF format signals.

ADAT Out: 8/4/2 channels at Single/Double/Quad Speed. Can optionally be used as 2-channel SPDIF optical output.

## AES/EBU

Breakout cable (BO968) provides one XLR AES/EBU input and output. Transformer-balanced and ground-free. Incoming channel status is ignored.

Can operate as second SPDIF I/O using RCA/XLR adapter cables. Pin 2 and 3 of XLR to RCA pins, shielding to pin 1 only.

Warning: AES/EBU and SPDIF can contain Emphasis information. Emphasis indication is lost as no standardized computer interface handles it.

## SPDIF (Coaxial, Optical)

Up to three SPDIF inputs and outputs: coaxial, optical, and AES can be used simultaneously with different audio signals. Sources must be synchronous (no sample rate converter).

SPDIF coaxial input accepts SPDIF and AES/EBU, Consumer and Professional format. AES/EBU input via adapter cable (female XLR to RCA).

Optical input automatically switches to SPDIF when detected, showing on ADAT channels 1/2 (channels 13-14 in TotalMix).

SPDIF coaxial output: Creates new header, ignoring received header. Channel Status selectable as Consumer or Professional. Professional mode doubles carrier level for AES/EBU compatibility.

SPDIF optical output: Select Output Format Optical - SPDIF in Settings. Signal must be on ADAT channels 1/2. Fixed to Consumer status.

## MIDI

One MIDI I/O via two 5-pin DIN sockets. Added to system as 'UCX II MIDI Port'. Supports multi-client operation (multiple programs can receive input simultaneously). MIDI output can be shared but bandwidth limitations may cause issues. MIDI input indicator displays all activity including Clock, MTC and Active Sensing.

## Word Clock

SteadyClock guarantees excellent performance with jitter suppression, refreshing any clock signal.

One BNC socket with dual functionality (input or output), set in Settings dialog.

Input Mode: Accepts Single, Double or Quad Speed, auto-adapts. Signal Adaptation Circuit works with signals as low as 300 mV (1.0 V with hysteresis). Terminatable with 75 Ohm internally. High impedance by default.

Output Mode: Constantly active, providing current sample frequency. In Master mode defined by software, in Slave mode matches input. Single Speed option keeps output in 32-48 kHz range. Low impedance, short circuit proof: 4 Vpp into 75 Ohm, 3.3 Vpp into 37.5 Ohm.

Cabling: Use BNC cables (75 Ohm RG59 for video/word clock). T-adapters for chain distribution. Terminate last device with 75 Ohm. SteadyClock recommendation: use Fireface word clock output instead of T-adapter pass-through for jitter-free distribution.

# Stand-Alone Operation



## General Stand-Alone Usage

Using the rotary encoder, four buttons and colour display, the UCX II can be completely configured without a computer. Six internal memory slots (Setups) for permanent storage. Can also be controlled via MIDI in stand-alone mode.

Button functions:
- MIC/GAIN: Mic Gain 1/2, then Line/Instr Gain 3/4
- REC/PLAY: Record/Playback (DURec) menu, then Rec/Play Settings
- CHAN/MIX: Channel menu (Settings, Low Cut, PEQ, Compressor/Expander, Auto Level), then Mix to menu (submix destination/source with level and pan)
- SETUP/REV: Options (Clock, Load/Store Settings, Hardware/Diagnosis, Control Room), then Reverb/Echo

## Store / Load Setups

Six user memory slots plus three fixed slots:
- Factory: Default state
- AD/DA: Configures 8-channel ADAT analog converter
- Clear Mix: Total Reset of TotalMix FX

Load/store via SETUP/REV > Options > Load/Store all Settings. Push encoder for >1 second to confirm.

Setups can be stored from computer via TotalMix FX: Options > Store current state into device.

## Stand-Alone Examples

- 8-Channel AD/DA Converter: Route analog inputs to ADAT outputs and ADAT inputs to analog outputs via TotalMix
- 2-Channel Mic Preamp: Route mic inputs directly to analog outputs (delay ~0.1 ms at 192 kHz)
- Monitor Mixer: Configure as monitor mixer for all I/Os with independent submixes for each output
- Digital Format Converter: ADAT to AES, AES/SPDIF to ADAT, etc.
- Analog/Digital Routing Matrix: Free routing of all inputs and outputs via Matrix
- Stand-Alone Recorder/Player: Record live concerts and play back from USB thumb drive without computer

# TotalMix FX



## Routing and Monitoring Overview

Powerful digital real-time mixer based on RME's TotalMix technology. Allows unlimited mixing and routing of all inputs and playback channels to any hardware output. Adds 3-band parametric EQ, Low Cut, Echo, Reverb, Compressor, Expander and Auto Level.

Capabilities:
- Up to 10 fully independent stereo submixes (equivalent to 20 Aux sends)
- Unlimited routing (patchbay functionality)
- Signal distribution to multiple outputs (splitter/distributor)
- Simultaneous multi-program playback via single output
- Complete ASIO Direct Monitoring
- Integration of external effects devices (insert, send/return)

Three-row layout (Inline desk style):
- Top row: Hardware inputs (level shown pre-fader)
- Middle row: Software playback channels (DAW tracks)
- Bottom row: Hardware outputs (total output level)

Submix View (default): Click output in third row to select submix, adjust faders in first and second row.

## Channel Controls

Each channel includes:
- Channel name (double-click to rename)
- Panorama control (-3 dB center)
- Mute and Solo buttons
- Numerical level display (RMS or Peak, updated 2x/sec)
- Level meter (peak as yellow line, RMS as green bar, overs in red)
- Fader (controls gain for current routing destination only)
- Trim Gain (T button): Synchronizes all channel routings to one fader
- Routing target field (shows all active routings with arrows)
- Arrow symbol to minimize/maximize channel width

Fader operations:
- Drag with left mouse button
- Mouse wheel adjustment
- Double-click for 0 dB / -infinity toggle
- Shift+drag for fine mode
- Shift+click to add to temporary fader group (yellow, ganged)

Context menus (right-click): Copy/Paste/Clear submixes, input mixes, and FX settings between channels.

## Channel Settings

Input channel settings:
- Stereo/Mono mode
- 48V phantom power (per channel)
- Inst mode (inputs 3-4, Hi-Z)
- Gain: Inputs 1-2: 0-75 dB. Inputs 3-8: 0-12 dB
- Level: +13 dBu / +19 dBu reference (rear inputs)
- AutoSet: Automatic gain reduction for overload protection
- Width: Stereo width (1.00 full stereo, 0.00 mono, -1.00 swapped)
- FX Send: Level to reverb/echo bus (locked to highest submix, Post Fader behaviour)
- MS Proc: Mid/Side encoding/decoding
- Phase L/R: 180° phase inversion per channel

Output channel settings:
- Level: +4 dBu, +13 dBu, +19 dBu (Line Out). Low/High (Phones)
- FX Return: Reverb/Echo mix level
- Crossfeed: 5 levels, max 4 stereo channels, Bauer Binaural method
- Room EQ: 9-band PEQ with Delay and Volume Calibration
- Talkback: Activates channel as talkback receiver/output
- No Trim: Excludes routing from Trim Gains function
- Loopback: Sends output data to driver as record data
- Cue button: Sends output audio to Main Out or Phones for monitoring

## Equalizer

Available on all input and output channels, affects all routings (pre-fader).

3-band parametric EQ:
- Bands 1 and 3: Bell, Shelving, High-Pass, Low-Pass modes
- Band 2: Fixed Bell mode
- Gain: +20 dB to -20 dB per band
- Frequency: 20 Hz to 20 kHz
- Q: 0.4 (wide) to 9.9 (narrow)

Low Cut: Separate activation, 6/12/18/24 dB per octave slope, 20 Hz to 500 Hz cut-off.

Internal headroom: 24 dB. Over LED indicates internal overload from extreme boost.

16 user preset slots plus 14 factory presets. Import/Export as .tmeq files. Presets shared across all channels. Not saved in Snapshots but saved in Workspaces.

## Room EQ

9-band parametric EQ for room correction, available only on output channels. Gain adjustable in 0.1 dB steps.

- Delay: 0 to 42 ms in 0.01 ms steps at all sample rates
- Vol.Cal: +3 dB to -24 dB in 0.1 dB steps
- Maximum 16 mono or 8 stereo channels of Room EQ
- Can be set differently for left and right in stereo channels
- Saved in Workspace by default; can optionally load with Snapshot
- Preset files use .tmreq extension (not compatible with .tmeq)
- Located after the 3-band PEQ in signal chain, recordable via Loopback
- Reset Mix menu offers options to preserve Room EQ during resets

## Dynamics

Available on all input and output channels, affects all routings.

Compressor:
- Threshold: -60 dB to 0 dB
- Ratio: 1:1 to 10:1
- Gain (makeup): -30 to +30 dB (also usable as universal digital gain stage)
- Attack: 0 to 200 ms
- Release: 100 to 999 ms

Expander:
- Threshold: -99 dB to -20 dB
- Same Ratio, Attack, Release controls

Auto Level:
- Max Gain: 0 to 18 dB
- Headroom: 3 to 12 dB
- Rise Time: 0.1 to 9.9 s

Graphics show amplitude response and current signal position. Blue lines in level meters show active gain reduction. 16 user presets plus factory presets.

## Control Room Section

Assign menu defines Main Out for studio listening. VOLUME knob follows this assignment.

Functions:
- Dim: Volume reduction (amount set in Settings)
- Recall: Sets predefined gain value
- Speaker B: Switches to Main Out B (faders can be linked)
- Mono: Mixes L+R for compatibility checking
- Talkback: Dims Phones outputs and sends control room mic to Phones
- External Input: Switches Main monitoring to defined stereo input
- Mute FX: Mutes Reverb/Echo on Main Out

Assign: Main Out, Main Out B (Speaker B), up to four Phones outputs. Cue/PFL output assignable to Main or Phones 1-4.

## Reverb and Echo

Accessed via FX in View Options.

Reverb Types:
- Rooms: Small, Medium, Large, Walls
- Shorty: Short, rich, warm reverb
- Attack: Slap back effect
- Swagger: Enriches and blows up source
- Old School
- Echoistic: Heavy echo within reverb
- 8plus9: Mix of Old School and Echoistic
- Grand Wide: Wide, open space
- Thicker: Short reverb to enrich signal
- Space: Most sizzle, longest reverb time
- Envelope: Freely adjustable volume envelope
- Gated: Simpler cut reverb effect

General Reverb Settings:
- PreDelay: 0 to 999 ms

## Snapshots and Groups

Eight Snapshot slots for mixer states. Each stores all mixer settings but no graphical elements. Store and recall via buttons. Snapshots are temporary until saved in a Workspace.

Four storage places each for fader, mute, and solo groups. Groups are per-Workspace, active across all 8 Snapshots. Mute groups work per-routing only. Solo groups operate like global solo within current routing.

## Channel Layout and Layout Presets

Options > Channel Layout: Hide channels from Mixer/Matrix, MIDI Remote 1-4, and OSC Remote 1-4. Hidden channels remain functional but invisible and non-editable. Hidden remote channels are skipped in 8-channel controller blocks.

Layout Presets: Store and recall channel visibility configurations. Useful for switching views between instrument sections. Sub button shows only channels in current submix. Double-click to rename presets. Stored in Workspace.

## The Matrix

Alternative monaural patchbay view. Horizontal labels = outputs, vertical = inputs + playback. Color coding: Green 0.0 dB = standard routing, grey with number = current gain, blue = muted, red = phase inverted, dark grey = no routing.

Operations: Ctrl+click for 0 dB toggle, drag up/down to change gain, double-click toggles 0 dB/mute. Ctrl+click on labels mutes all crosspoints in row/column. Shift+click on labels toggles phase. Mono Mode button controls whether actions affect one or two channels.

Matrix and Mixer views are always synchronized.

# MIDI Remote Control



## MIDI Remote Control Overview

Compatible with Mackie Control protocol. Supports hardware controllers like Mackie Control, Tascam US-2400, Behringer BCF 2000.

Main Out (Control Room) also controllable via standard Control Change Volume on MIDI channel 1.

Always operates in Submix View mode.

## Mackie Control Mapping

Supported surface elements:
- Channel faders 1-8: Volume
- Master fader: Main Out fader
- V-Pots 1-8: Pan (press to center)
- CHANNEL LEFT/RIGHT or REWIND/FAST FORWARD: Move one channel
- BANK LEFT/RIGHT or ARROW LEFT/RIGHT: Move eight channels
- ARROW UP/DOWN or PAGE+/-: Move one row up/down
- EQ: Master Mute
- PLUGINS/INSERT: Master Solo
- STOP: Dim Main Out
- PLAY: Talkback
- PAN: Mono Main Out
- FLIP: Speaker B
- DYN/INSTRUMENT: TrimGains
- MUTE Ch. 1-8: Mute
- SOLO Ch. 1-8: Solo
- SELECT Ch. 1-8: Select
- REC Ch. 1-8: Select output bus (Submix)
- RECORD: Recall
- F1-F8: Load Snapshot 1-8
- F9: Select Main Out
- F10-F12: Select Cue Phones 1-3

## MIDI Control Commands

Note On/Off commands on MIDI channel 1 (hex / decimal / key):
- Dim: 5D / 93 / A6
- Mono: 2A / 42 / #F2
- Talkback: 5E / 94 / #A6
- Recall: 5F / 95 / B6
- Speaker B: 32 / 50 / D3
- Cue Main Out: 3E / 62 / D4
- Cue Phones 1: 3F / 63 / #D4
- Cue Phones 2: 40 / 64 / E4
- Cue Phones 3: 41 / 65 / F4
- Cue Phones 4: 42 / 66 / #F4
- Snapshot 1-8: 36-3D / 54-61 / #F3 to #C4
- Trim Gains: 2D / 45 / A2
- Master Mute: 2C / 44 / #G2
- Master Solo: 2B / 43 / G2

Control Change format for faders: Bx yy zz
- x = MIDI channel (1-4: first row, 5-8: middle row, 9-12: bottom row)
- yy = controller 102-117 (hex 66-75), 16 controllers per MIDI channel
- zz = value

Examples:
- Input 1 to 0 dB: B0 66 68
- Input 17 to min: B1 66 0
- Playback 1 to max: B4 66 7F
- Output 16 to 0 dB: B8 75 68

Additional CC commands:
- Trim Gains On: BC 66 xx (channel 13)
- Trim Gains Off: BC 67 xx
- Select submix: BC 68/69 xx (ch 1/2), BC 6A/6B xx (ch 3/4), etc.
- Input Gain: CC9 on channels 1-16, value range 0-65
- Reverb Presets 1-16: B2 0C nn
- Echo Presets 1-16: B3 0C nn

## Stand-Alone MIDI Control

Activated in unit's menu: Options > Hardware/Diagnosis > Standalone MIDI.

Supports Mackie Control protocol and standard MIDI functions. Available functions:
- All faders and pans of first and third row
- Mute per channel
- Ganging via Select
- Routing destination selection
- LED and display data to controller

Not available (software-only): Talkback, Mono, Solo, relative ganging, Monitor Main/Phones.

Stand-alone Mackie elements same as online mode except: no Master fader, SOLO, PLAY. F1-F6 load Setup 1-6 instead of Snapshots.

Additional stand-alone MIDI notes on channel 1:
- Dim: 5D / 93 / A6
- Setup 1-6: 36-3B / 54-59 / #F3 to B3

Loopback Detection: TotalMix sends special MIDI note every 0.5 seconds. If detected at input, MIDI is disabled. Re-enable via Options > Enable MIDI Control.

## OSC (Open Sound Control)

Network-based remote control protocol. Supports apps like TouchOSC and Lemur on iPad.

Up to four independent OSC remote controls. Settings per index:
- Local IP/Host Name displayed
- Port incoming/outgoing (typical: 7001/9001 or 8000/9000)
- Remote IP or Host name
- Peak Level Data transmission with Peak Hold
- Lock Remote to specific submix
- Number of faders per bank: 8, 12, 16, 24, 32, 48
- Compatibility mode for older controllers

OSC implementation chart and free iPad template available from RME website.

## DAW Mode

Simplified operational mode for users who handle all routing in their DAW. Activated via Options > Operational Mode > Digital Audio Workstation Mode.

Features: Two rows only (no playback row), no mixing faders in input row, 1:1 routing only. Hardware controls (gain, phantom, instrument) and output levels available.

Still available in DAW mode: Talkback, External Input, Phones handling, Speaker A/B, all FX (EQ, Dynamics, Echo, Reverb), Mute, Solo, Cue/PFL.

## TotalMix Remote

Remote control app for TotalMix FX via network/WiFi. Mirrors complete mixing state including level meters in real-time. Supports up to three hosts. Available for iPad (free from App Store), Windows, and Mac.

Setup: Enable TotalMix Remote Server in Options > Network Remote Settings. Enter host IP on remote device. Default port 7009.

User management with configurable access rights: view only, specific submix control, or full access.

Limitations: GUI states (panel open/close, window size) not synced. Workspaces saved locally on remote for personalized views. Performance depends on network quality. No iPad background operation.

# Class Compliant Mode

Native USB mode supported by Windows, Mac OS X, Linux, and iOS without proprietary drivers. Activated at unit: SETUP/REV > Options > Hardware/Diagnosis > CC Mode On (USB must be disconnected).

Primary purpose: Connecting to Apple iPad/iPhone. Provides professional analog I/O, mic preamps with EQ/dynamics/AutoSet, balanced line outputs, hi-power headphone output, AES/ADAT I/O, reverb/echo, zero latency monitoring. Up to 96 kHz/24 bit on iOS. Sysex-capable MIDI I/O.

Requirements: Apple iPad with iOS 6+, iPhone with iOS 7+, Camera Connection Kit or Lightning to USB adapter. iPad Pro: USB-C to USB-B cable only.

Supported I/O on iPad: Input 1 (mono apps), 1-2 (stereo), up to 8 or 20 inputs depending on app. Playback on analog outputs 1/2 plus optional copies.

CC Mix Modes:
- TotalMix App: Locks settings for use with TotalMix FX for iPad app
- 8 Ch. + Phones: 8 playback channels, 1/2 copied to Phones/SPDIF/ADAT 1-2
- 8 Ch. Playback: Same without Phones copy
- 20 Ch. Playback: All channels separate

CC Mode Audio MIDI Setup (Mac) shows 8, 14, 16, and 20 channel modes. 8/14 channels support up to 192 kHz. 20 channels limited to 96 kHz.

Not compatible with Windows in CC mode.

# DURec - Direct USB Recording



## DURec Overview

Record and playback up to 40 channels via rear DURec USB-A port. Independent from computer (DSP-based). Available in all modes including stand-alone and Class Compliant.

Media: FAT32 formatted, primary partition. Recording as 24-bit WAV, files up to 2 GB each (auto-split with incremental naming: UFX01_00.wav, UFX01_01.wav, up to 100 files).

Channel limits:
- 48 kHz: up to 40 channels
- 96 kHz: up to 32 channels
- 192 kHz: up to 16 channels

Recording signal taken before EQ and Dynamics on both inputs and outputs. To record with EQ/Dyn, activate REC on output and route processed signal there.

## DURec Operation

TotalMix FX DURecorder panel controls: File selection, Info, Delete, transport bar (Stop, Play/Pause, Record, Previous/Next File).

Record View: Mute/Solo replaced by Play/Record arm buttons. Playback assignable to any outputs or mixer inputs (for processing with FX).

Playback Modes:
- Single: Stop after current file
- Single next: Stop after current, advance to next
- UFX single: Play all consecutive files from one recording session
- Continuous: Play all files consecutively
- Repeat single: Loop current file
- Repeat all: Loop all files

Unit display: REC/PLAY button shows File, Status, Time, Transport controls. Rec/Play Settings subpages: USB Media, Record, Playback, Time & Date.

DURec/Partition setting allows disabling DURec (frees DSP resources) or selecting partition number. Real-time clock for file timestamps, settable manually or auto-set from computer.

## DURec Limitations and Performance

Media must be FAT32, primary partition. Recording stops on sample rate change. Channel configuration cannot change during recording. Channels recorded in ascending order without labels.

Playback does not change sample rate (must be set manually). Plays 16 or 24 bit WAV files. Playback can be assigned to multiple outputs.

Performance indicators:
- USB Load: Should not exceed 80% sustained
- Errors: Must be 0 for acceptable recording
- Max R/W Time: Quick media (SSD/HDD) ~80-100 ms, slow thumb drives can exceed 800 ms

Recommended media:
- SATA SSD with USB 3 adapter (best performance)
- SSD-based thumb drives
- Mobile hard drives with USB port
- Micro SD cards (U3/V30 spec) in USB adapter, formatted FAT32

RME Multichannel WAV File Batch Processor: Free tool to split multi-channel interleaved files into single/dual channel files, combining consecutive 2 GB files. Supports RF64 and CAF output. Preserves metadata (date, time, channel names).

## SteadyClock FS Technology

RME's SteadyClock technology provides jitter suppression for all clock modes. Combines high-speed digital synthesis, digital PLL, and 800 MHz sample rate within the FPGA with analog/digital filtering.

Performance: Locks in fractions of a second, follows extreme varipitch, locks 28 kHz to 200 kHz. Converts 50 ns input jitter to < 2 ns output. Sampling jitter in picosecond range. Identical performance on internal and external clock.

SteadyClock FS improvement: Attenuates jitter > 1 Hz. At 50 Hz modulation frequency with 400 ns input jitter, approximately 210 ps detected (> 65 dB suppression).

## Latency and Monitoring

Zero Latency Monitoring: Digital path from input to output causes ~3 samples delay (68 μs at 44.1 kHz, 15 μs at 192 kHz).

Converter delays (AD: 5 samples, DA: 5.8 samples):
- 44.1 kHz: AD 0.11 ms, DA 0.13 ms
- 48 kHz: AD 0.10 ms, DA 0.12 ms
- 88.2 kHz: AD 0.057 ms, DA 0.066 ms
- 96 kHz: AD 0.052 ms, DA 0.06 ms
- 176.4 kHz: AD 0.034 ms, DA 0.033 ms
- 192 kHz: AD 0.031 ms, DA 0.03 ms

Buffer size of 64 samples at 44.1 kHz = 1.5 ms latency each direction. Software compensates via offset reporting (ASIO/Core Audio).

Safety Buffer: Windows 32 samples, Mac 24 samples (added to buffer size). Core Audio Safety Offset: 24 samples (Short option: 12 samples).
