## Session

Pad = launch clip | Col 8 = launch scene (green) | Shift+pad = select | Even steps = stop trk | Step 16 = stop all | Shift+Note/Sess = overview | L/R = move ring (Shift=7 trks)

## Note Mode *(auto: Instrument / Drum / Slicing)*

Pad→step = add note | Step = remove | Loop btn = bars view | +/- = octave/navigate pads (Drum: Shift=4)
