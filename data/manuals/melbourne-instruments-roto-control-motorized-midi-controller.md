# Introduction

Roto-Control is a motorized MIDI controller for software and hardware. It brings Melbourne Instruments' motorized technology to a MIDI controller in a powerful, portable, affordable tool for studio and live applications. Key features include fully assignable motorized touch-sensitive knobs, user-definable haptics for detailed control, high-res screens providing easy-to-read labels for every control, and internal memory with storage for thousands of assignments. Three main modes of operation: MIX, PLUGIN, and MIDI with Motion Recorder.

The patent-pending motorized knobs are a world first for MIDI controllers, custom designed from brushless drone motor design. They are extremely robust with high reliability that will practically never wear out. Position sensing uses a contactless optical system with extremely high resolution and ultra-low noise.

# Overview

The Roto-Control hardware consists of a front panel with touch-sensitive motorized knobs, LCD (IPS) displays for each control, a menu window, backlit RGB LED buttons, and a control panel with mode and function keys. The rear panel includes USB-C ports for power and computer connection, 5-pin MIDI IN, OUT, and THRU ports, and a service button.

## Front Panel

Touch-sensitive motorized knobs with individual LCD (IPS) displays. Menu window for status and navigation. Backlit RGB LED buttons. Control panel with dedicated function keys.

## Rear Panel I/O

USB-C ports for power and computer connection. 5-pin MIDI IN, OUT, THRU. Service button (used when directed by Melbourne Instruments).

## Control Panel Buttons

MODE: Select mode — MIX, MIDI, PLUGIN.
LEARN: Assign MIDI parameters to knobs and buttons.
FUNC: Mode-specific functions.
TRANSPORT: Ableton Live control in MIX and PLUGIN Modes; universal MIDI start/stop in MIDI Mode.
SEL: Select button with additional mode-specific functions.
LOCK: Mode-specific functions.
NAVIGATION (Arrow Keys): Navigate pages, tracks, plugins, and parameters.

# Modes of Operation — Quick Reference

Press MODE to select from MIX, PLUGIN, and MIDI modes.

MIX: Plug & play dedicated Ableton Live audio mix environment. Automatically syncs your Ableton Set with all track names and colors instantly appearing on Roto-Control displays.

PLUGIN: Instant plugin recall from Ableton Live. Plugin parameters and labels are directly taken from Ableton Live with one-touch, one-time intuitive setup. Assignments stored on Roto-Control for faster workflow.

MIDI with Motion Recorder: Control MIDI hardware and software — synths, DAWs, lighting, media applications and more. Motion Recorder brings motorized automation to external gear.

## Console Functions by Mode

Within each mode the console buttons perform different functions, except MODE which always returns to the Mode selection page.

# System Settings

Access the system menu by pressing SYSTEM > MODE.

STORE DEMO: Automatically cycles through Roto-Control features for in-store demonstration. No functional value. Exit by pressing FUNC + both arrow keys.

SENSITIVITY: Adjusts touch sensitivity for knobs. 9 settings from LOW to HIGH. Default is NORMAL 5. Increase if knobs are not responding; decrease if experiencing false touches. Strong electromagnetic fields can cause false touches.

ABOUT: Displays current firmware version and unique serial number.

# Getting Started

Download and install the Roto-Setup App from www.melbourneinstruments.com/roto. Connect Roto-Control to your computer via the port labelled 'USB' and the App will update the device with the latest firmware.

## Using Ableton Live with Roto-Control

Roto-Control must be selected as a Control Surface in Ableton Live. Open Settings > Link, Tempo & MIDI tab. Ensure ROTO CONTROL is selected as a Control Surface with Roto-Control selected as Input and Output device. Tick Track, Sync, and Remote boxes for both Input and Output Ports.

# MIX Mode

MIX Mode is a fast and intuitive way to control the audio environment of Ableton Live. Roto-Control displays track names and colors directly from the active Ableton Live set. No setup required; all data is taken from the active set.

Touching a knob selects the corresponding track in Ableton Live. Use arrow keys to navigate tracks, with up to 64 tracks available across 8 pages. All communication is bidirectional — actions in Ableton Live are reflected immediately on Roto-Control and vice versa.

## MIX Mode — SEL (Select)

Knobs default to volume; buttons default to track activation (on/off). Hold SEL to change the function for the main page of controls.

Knob assignments: VOLUME, PAN, or any SEND (A through L). The menu window displays current knob assignments.

Button assignments: track ON/OFF, SOLO, or ARM REC. To solo or arm-record more than one track at a time, ensure exclusive Arm and Solo are deselected in Ableton Live settings.

## MIX Mode — FUNC / Track Focus

Pressing FUNC enters Track Focus where all knobs for the selected track are accessible: control of SENDs, PAN, and volume for the selected track. Communication is bidirectional — selecting a track on Ableton Live also selects the track on Roto-Control; moving a fader in Ableton Live also moves the knob on Roto-Control.

## MIX Mode — Arrow Keys / Return and Main Tracks

Press both arrow keys simultaneously to access return and main (master) tracks. Arrow keys blink green to indicate return track access. Roto-Control displays up to 12 return tracks. Press both arrow keys again to exit.

## MIX Mode — Lock Button

Turns off touch sensitivity, preventing track changes when touching knobs. You can still navigate and change tracks on screen; Roto-Control will not follow until lock is disengaged.

## MIX Mode — Transport Controls

Press transport button for Ableton Live transport controls. Use arrow keys in transport control to navigate arrangement position. MIX Mode and PLUGIN Mode share the same Ableton Live transport controls — you can freely switch between modes without interrupting workflow, playback, or recording.

# PLUGIN Mode

Roto-Control has a highly flexible approach to controlling and learning Ableton Live devices and third-party plugin parameters. You choose which parameters to map and where they are assigned on the Roto-Control.

When learning parameters, Roto-Control automatically takes the label of the parameter and displays it on the knob/button window. Every mapped parameter is automatically saved on the unit — learn a parameter once and each time you recall a device/plugin your previously learnt parameters will appear instantly.

Capacity: Up to 64 devices/plugins, with up to 128 controls per device/plugin saved on Roto-Control. More can be saved externally via the Roto-Setup App.

## PLUGIN Mode — SEL (Select)

Hold SEL to see all devices/plugins on the selected track. Select a plugin/device by pressing the respective button. Roto-Control has bidirectional communication with Ableton Live — selecting a device/plugin in Ableton Live instantly displays the same on Roto-Control with knobs snapping to parameter positions.

Toggle SEL to activate/deactivate (mute) devices/plugins on the selected track.

## PLUGIN Mode — FUNC (Function Key)

Press FUNC to see the tracks from the active Ableton Live Set. Press the respective button to choose the desired track. Navigate pages with arrow keys. You can also choose a different track by switching to MIX Mode.

## PLUGIN Mode — Arrow Keys

Navigate up to 8 pages of controls (64 knobs and 64 buttons) per device/plugin.

## PLUGIN Mode — Transport Controls

PLUGIN Mode shares the same Ableton Live transport controls as MIX Mode. You can freely switch between these two modes without interrupting playback or recording.

## PLUGIN Mode — Lock Button

When pressed, blinks green to indicate Roto-Control is locked to the current device/plugin. This allows navigating other areas of Ableton Live without Roto-Control changing controls. Ideal for performing and focusing on a single device or plugin. Press LOCK again to deactivate.

## Mapping and Learning Devices/Plugins

Roto-Control's flexible learning behavior allows you to choose the parameters you want to control and where they reside on the Roto-Control. The exception is Macros (part of instrument and effects racks), where no learning is required — Roto-Control displays Macro control labels directly from the selected rack.

### Learning Ableton Live Devices and Native Audio Effects

Steps to learn parameters:
1. Press LEARN — displays '--' on each window indicating available knobs/buttons.
2. Touch any knob or button to map a parameter to. The window displays LEARNING.
3. On the active Ableton Live set, click or move the parameter on the device/plugin. Roto-Control instantly maps the parameter and displays its label.
4. Press LEARN to confirm. Continue learning more parameters by repeating steps 2-3.

Notes: Knobs and buttons are independent — you can learn any parameter to either control type (e.g., map a pot to a button to create an on/off switch). Default color for mapped parameters is dark blue with white text, customizable in Roto-Setup App. Assignments automatically save to Roto-Control's memory and instantly appear when the same device/plugin is recalled.

### Working with Third-Party Plugins and Instruments

To use third-party plugins with Roto-Control's recall system, first configure the parameters:

1. Select the plugin and drop it into a track on Ableton Live.
2. Click unfold the device parameters button.
3. Click the Configure button (turns green) — plugin waits for parameters.
4. Click the parameters on the plugin window you want to control. They appear as device parameters.
5. Click Configure button to confirm (turns from green to grey).
6. Right-click the device title bar and choose 'Save as Default Configuration' — ensures Roto-Control can recall the plugin with mapped parameters every time, including multiple instances per session.
7. LEARN the parameters to Roto-Control as described in the native effects section.

Note: When using multiple instances of the same plugin in different racks, Roto-Control recognizes presets within the plugin and knobs instantly snap to position.

### Clearing Mapped/Learnt Parameters

1. Hold the LEARN button (it flashes red).
2. Touch the knob or button you wish to clear.
3. The window displays 'CLEAR?' in red — touch again to confirm.

If you make a mistake, you can always re-learn a control.

### Working with Instrument/Drum and Audio Effects Racks and Macros

Ableton Live instrument and audio effect racks contain various devices/plugins bundled into one device. Multiple parameters can be controlled by a single macro with up to 16 controls.

Roto-Control instantly maps macro controls (up to 16 knobs across 2 pages) per macro/rack, taking data directly from the selected macro/rack. No learning or mapping required — works similar to MIX Mode.

Macros are displayed in light blue on Roto-Control displays. Renaming macro labels is done on the rack/macro in the active Ableton Live Set and reflected immediately. Macro mappings are not stored on Roto-Control and do not impact memory usage.

Roto-Control recognizes multiple macros within a single track (e.g., an instrument rack and effects rack in the same channel). Individual device/plugins within a rack that have been mapped will also appear instantly when recalled.

### Working with Automatic Macro Mapping

Automatic mapping of rack/macros relates to .adg files (Ableton device group) — instrument/effects racks with macros. This is not automatic mapping of all plugins and parameters.

Two ways to turn any plugin/device into a rack/macro:
1. Create an empty rack and drop plugins into it.
2. Within a track, select the plugin(s) and group them (Cmd+G).

This creates a macro that can be mapped internally to plugins within that group. Macro controls are automatically mapped to Roto-Control's knobs. New macros default labels to Macro 1-16; greyed out labels won't appear on Roto-Control until macro controls are mapped to parameters within the rack.

# MIDI Mode

Control any MIDI-compatible hardware and software: synths, DAWs, lighting, and more. Motion Recorder brings motorized automation to external gear. Record and automate MIDI parameters via the Motion Recorder.

MIDI Mode features the same flexible learning behavior as PLUGIN Mode but can also work like a traditional MIDI controller. Learn up to 64 MIDI parameters per setup and store up to 64 Setups on Roto-Control for easy recall. MIDI Mode can operate in stand-alone mode without the need of a computer.

## Mapping and Learning MIDI Parameters

Three ways to map MIDI parameters to Roto-Control:
A. Enter MIDI values directly on the Roto-Control.
B. Learn MIDI channel and CC values from an external device that outputs CC.
C. Enter MIDI values via the Roto-Setup App.

### Entering MIDI Values Directly on the Roto-Control

1. Press LEARN and select the knob or button to map (use arrow buttons to navigate pages 1-4). LEARN button flashes.
2. Enter the MIDI channel using the 'MIDI CH' knob.
3. Enter the MIDI CC value using the 'MIDI CC' knob.
4. Optional: set MIN VALUE and MAX VALUE via their respective knobs. Set display color via the COLOR knob (13 colors available).
5. Press LEARN to confirm and exit.

All assigned controls are automatically saved in the current selected Setup. Default label displays as 'CH:01/CC:33' format. Further customization available in the Roto-Setup App (labels, colors, haptics, resolution).

### Entering MIDI Values via External Gear

Ensure the external device can output MIDI CC and this option is enabled.

1. Connect external gear for 2-way communication via USB-C, or serial MIDI OUT of Roto-Control to MIDI IN of external device and MIDI IN of Roto-Control to MIDI OUT of external device.
2. Press LEARN and select the knob or button to assign (navigate pages 1-4).
3. On the external device, move or press the parameter you want to control. Roto-Control displays the MIDI channel and CC immediately.
4. Optional: set MIN VALUE, MAX VALUE, and COLOR.
5. Press LEARN to confirm and exit.

Default label displays as 'CH:01/CC:33' format.

### Map MIDI Values via the Roto-Setup App

MIDI values can also be entered and mapped through the Roto-Setup App interface. See the Roto-Setup App section for details.

### Clearing a MIDI Mapped Assignment

1. Press LEARN and select the knob or button to clear (use arrow buttons to navigate pages 1-4).
2. Press CLEAR to immediately clear the assigned MIDI values.
3. Press LEARN to exit.

MIDI assignments can also be cleared via the Roto-Setup App.

### Using Roto-Control as a Traditional MIDI Controller

Roto-Control knobs and buttons are not pre-populated with MIDI channel or CC numbers. For DAWs and software other than Ableton Live, you must first assign MIDI values to controls.

Select a new MIDI Setup (blank displays indicate no values mapped). Two ways to create a setup:
1. Download MIDI Setup templates from melbourneinstruments.com/roto-templates for various software and hardware. Import via Roto-Setup App.
2. If no template exists, assign values manually on the device or via the Roto-Setup App.

Important: ensure the MIDI Channel mapped correlates to the DAW parameters you are controlling.

## MIDI Setups

Press SEL to access up to 64 MIDI Setups. Setups can be renamed and imported/exported via the Roto-Setup App.

## Motion Recorder

The Motion Recorder brings Melbourne Instruments' motorized knob technology to MIDI-compatible gear. It is a creative way to automate mapped MIDI parameters on the Roto-Control.

Motion Recording can automate the first 1-8 knobs. Only MIDI Setups 1-16 can save recorded motion.

### Motion Recorder Settings

Press FUNC in MIDI Mode to enter Motion Recorder settings.

Synchronization: Choose internal clock (INT CLK) or external MIDI clock (EXT CLK). Selected clock displays with an orange label.

BPM: Set for INT CLK, range 20-240 BPM.

Motion Recorder Length: Choose 16, 32, 48, or 64 steps. 1 step = 1/4 note.

Press FUNC again to confirm and exit.

### Motion Recorder Transport and Playback

Press the transport button to enter Motion Recorder controls.

PLAY: Start playback (INT CLK) or wait for external MIDI clock (EXT CLK). Press again to pause. Transport button blinks blue during playback. You can exit transport controls during playback to navigate Roto-Control; playback continues. During playback you can grab knobs to take over control — releasing returns to recorded automation.

STOP: Stops playback.

RECORD: Commences recording of knobs 1-8. Transport button blinks red during recording, changes to blue when recording length is reached. With EXT CLK, recording starts when MIDI clock is received.

ERASE: Displays erase options for knobs 1-8 (red displays). Touch any knob to erase its automation (display changes from red to orange). Press ERASE button to exit.

Note: Automation is saved automatically to the current MIDI Setup when the Motion Recorder has stopped playback. You can continuously record and erase until satisfied.

Note: MODE, LEARN, and SEL are not available during playback. Stop playback to access these functions.

### Playback Modes

FWD: Forward — default playback direction. Automation can only be recorded in FWD mode.
BWD: Backwards — opposite to recording direction.
RAND: Randomized playback.
PING PONG: Playback alternates forward and backward continuously.

# Roto-Setup App

The Roto-Setup App keeps Roto-Control up to date, provides customization of controls, and enables import/export of setups in MIX and PLUGIN Modes. The app window reflects the current selected page and controls when connected. Changes made in the app are reflected immediately on the Roto-Control.

The first time the app is installed, it searches for your Ableton Live User Library. If moved from the default location, you will be prompted to locate it. Relocate anytime via menu: File > Select Ableton Live User Library.

## Updating Firmware

The latest Roto-Setup App includes the latest firmware.

1. Download the latest Roto-Setup App from the Melbourne Instruments website.
2. Install on your computer.
3. Open the app and connect Roto-Control via USB-C through the 'USB' port.
4. Confirm the update prompt.
5. Displays go blank during update — do not disconnect. Roto-Control restarts automatically.

Highly recommended: back up via 'EXPORT ALL' in the Roto-Setup App before updating firmware.

## Customizing Roto-Control with the Roto-Setup App

The Roto-Setup App can customize knobs and buttons in MIDI and PLUGIN Modes. MIX Mode and Macros (in PLUGIN Mode) are configured in the active Ableton Live Set and cannot be customized with the app.

To customize: select MIDI or PLUGIN Mode on Roto-Control and the app displays the selected Mode and page.

### Customizing a Knob in PLUGIN Mode

DISPLAY NAME: Click and type to change. Defaults to the learnt device/plugin parameter name.
COLOR: Click to change from dark blue. Full color palette available.
TYPE: KNOB or STEP (stepped knob/switch with haptic feel). Set automatically from the learnt parameter.
INDENT 1 & 2: Add up to 2 indents (available when TYPE: KNOB).
STEPS: When TYPE: STEP, add up to 24 steps creating a stepped knob/switch. First 16 steps can be named with unique display labels. Plugin mode supports up to 24 steps but names are limited to the first 16.
MIN VALUE: Set minimum value.
MAX VALUE: Set maximum value.

Note: Take care when changing TYPE, MIN, or MAX from assigned parameter defaults as results will vary.

### Customizing a Button in PLUGIN Mode

DISPLAY NAME: Click and type to change. Defaults to the learnt parameter name.
COLOR: Click to change from dark blue. Full color palette available.
ON COLOR: RGB color when button is pressed. Default: white.
OFF COLOR: RGB color when button is not pressed. Default: black (no color).
TYPE: PUSH or TOGGLE. Default set from learnt parameter. When TOGGLE, add up to 16 steps creating a stepped switch with unique names per step.
OFF VALUE: Click to change.
ON VALUE: Click to change.

Note: Take care when changing values from defaults set by the learnt parameter.

### Importing and Exporting PLUGIN Setups

PLUGIN Setups are saved as .json files.

Exporting:
1. Select PLUGIN Mode.
2. Select the device/plugin to export.
3. In Roto-Setup App: File > Export. Save as .json.

Importing:
1. Select PLUGIN Mode.
2. In Roto-Setup App: File > Import. Choose the .json file.
3. Setup is flashed to Roto-Control. If the same plugin exists, you'll be prompted that it will be overwritten.

Recommendation: Save PLUGIN and MIDI Setups in one location as they share the .json file extension.

### Mapping and Customizing Knobs in MIDI Mode via Roto-Setup

DISPLAY NAME: Click and enter text. Default is 'KNOB #'.
COLOR: Click to change. Default is orange.
MIDI CH: Click to enter MIDI channel.
MODE: Choose CC or NRPN.
MIDI CC: Click to enter CC number.
RESOLUTION: Choose COARSE or FINE. When FINE is selected in CC mode, enter MIDI CC MSB between 0-31 (LSB adjusted automatically). When FINE in NRPN mode, enter NRPN ADDR.
TYPE: KNOB or STEP.
MIN VALUE: Default 0.
MAX VALUE: Default 127 (CC) or 16383 (NRPN FINE).
INDENT 1 & 2: Add up to 2 indents (TYPE: KNOB only).
STEPS: When TYPE: STEP, add up to 16 steps creating a stepped knob/switch. Each step can be individually named.

### Mapping and Customizing Buttons in MIDI Mode via Roto-Setup

DISPLAY NAME: Click and enter text. Default is 'BUTTON #'.
COLOR: Click to change. Default is orange.
ON COLOR: RGB color when pressed. Default: white.
OFF COLOR: RGB color when not pressed. Default: black.
MIDI CH: Click to enter MIDI channel.
MIDI CC: Click to enter CC number. Some CC numbers are reserved for Roto-Control operation.
TYPE: PUSH or TOGGLE. When TOGGLE, add up to 16 steps with unique names.
OFF VALUE: Click to change.
ON VALUE: Click to change.

Note: Results will vary across MIDI devices — some may swap ON/OFF orientation.

### Changing MIDI Setup Name

Each MIDI Setup can have a unique name. Defaults are SETUP 01 through SETUP 64. Click the MENU window display and a pop-up window appears to enter a new name.

### Exporting a MIDI Setup

1. Select MIDI Mode.
2. Choose the MIDI Setup to export (current active setup is selected by default; press SEL to change).
3. In Roto-Setup App: File > Export. Save as .json.

Recommendation: Save MIDI and PLUGIN Setups in one location as they share the .json extension.

### Importing a MIDI Setup

1. Select MIDI Mode.
2. Select the target MIDI Setup on Roto-Control.
3. In Roto-Setup App: File > Import. Choose the .json file.
4. Setup is flashed to Roto-Control. You'll be prompted that importing will overwrite the existing setup.

## Export All — Backing Up Roto-Control

All MIDI and PLUGIN Setups can be saved to your computer.

1. In Roto-Setup App: File > Export All.
2. Choose save location.
3. App creates a folder named 'ROTO-CONTROL YEAR DATE TIME' containing two folders: MIDI and PLUGIN.

To restore: import the .json files individually from the backup folder.

# Specifications and Capacity Summary

Tracks in MIX Mode: up to 64 (across 8 pages)
Return tracks: up to 12
Sends: A through L
Devices/plugins stored: up to 64
Controls per device/plugin: up to 128 (64 knobs + 64 buttons across 8 pages)
MIDI Setups: up to 64
MIDI parameters per setup: up to 64
Motion Recorder: knobs 1-8, Setups 1-16 only
Motion Recorder length: 16, 32, 48, or 64 steps (1 step = 1/4 note)
BPM range (internal clock): 20-240 BPM
Macro controls per rack: up to 16 (across 2 pages)
Knob steps (PLUGIN mode): up to 24 (first 16 nameable)
Knob steps (MIDI mode): up to 16 (all nameable)
Button toggle steps: up to 16
Display colors: 13 available via on-device COLOR knob; full RGB palette via Roto-Setup App
Touch sensitivity settings: 9 levels (LOW to HIGH, default NORMAL 5)
MIDI CC resolution: COARSE (standard) or FINE (MSB 0-31 with auto LSB, or NRPN with max 16383)
Connectivity: USB-C (power and data), 5-pin DIN MIDI IN/OUT/THRU
Setup file format: .json (shared between PLUGIN and MIDI setups)
Playback modes: FWD, BWD, RAND, PING PONG
Compatibility: Ableton Live (native Control Surface integration), any MIDI-compatible hardware/software via MIDI Mode
